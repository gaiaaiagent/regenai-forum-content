MCP Server

Exposes capabilities through three universal primitives

📚

Resources

The Data Layer. Resources expose information that AI systems can read and use as context. They are application-controlled, meaning the client explicitly requests and manages access.

Examples

  • File contents and documents
  • Database records
  • Configuration values
  • Session state
🔧

Tools

The Action Layer. Tools are executable functions that AI can invoke to perform actions. They are model-controlled, meaning the AI decides when to call them based on user intent.

Examples

  • Load and analyze datasets
  • Execute API calls
  • Modify system state
  • Generate visualizations
✨

Prompts

The Orchestration Layer. Prompts are reusable templates that compose tools into workflows. They encode expertise and guide AI through complex multi-step processes.

Examples

  • Guided review workflows
  • Analysis pipelines
  • Discovery sequences
  • Best-practice patterns

The Mycelial Network Metaphor

Just as mycorrhizal networks beneath a forest floor connect trees without central coordination, MCP enables any AI system to connect to any data source or tool through a universal protocol. Each server maintains autonomy over its own capabilities while becoming transparently available to others. The result: emergent intelligence at planetary scale, where the whole becomes greater than the sum of its parts.
