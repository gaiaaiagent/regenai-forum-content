Registry Review Agent: Eight-Stage Workflow

A collaborative process where AI handles the tedious and humans bring the expertise. Like digestion: intake, breakdown, synthesis, validation, and finally transformation into knowledge that nourishes the ecosystem.

1
Initialize
The Intake Breath - receiving and preparing
Agent Actions
  • Create unique review session ID
  • Accept uploaded files or folder links
  • Load checklist template for methodology
  • Generate Resource Descriptors with checksums
Human Actions
  • Select project and checklist template
  • Choose data source mode (Mirror/Reference)
  • Confirm session creation
Output
  • Session metadata record
  • Resource Descriptors with IRIs
  • Status: Initialized
1
2
Document Discovery
Sensing the Landscape - exploring what exists
Agent Actions
  • Scan folders and extract file metadata
  • Normalize file names for clarity
  • Classify by type: reports, legal, GIS, data
  • Generate inventory with confidence scores
Human Actions
  • Review document inventory
  • Mark as In Scope, Ignored, or Pinned
  • Correct misclassifications
Output
  • Document inventory table
  • Classification accuracy: >85%
  • Status: Documents Discovered
2
3
Requirement Mapping
Building Correspondence - connecting needs to evidence
Agent Actions
  • Parse checklist into structured requirements
  • Analyze documents with semantic matching
  • Suggest document-to-requirement mappings
  • Flag unmapped requirements
Human Actions
  • Review mapping matrix
  • Confirm, remove, or add mappings
  • Prioritize unmapped requirements
Output
  • Requirement mapping matrix
  • Mapping accuracy: >90%
  • Status: Requirements Mapped
3
4
Evidence Extraction
The Digestion Process - breaking down into nutrients
Agent Actions
  • Parse documents: PDF text, tables, metadata
  • Extract 0-3 evidence snippets per requirement
  • Extract structured data: dates, locations, values
  • Generate citations with page/section
Human Actions
  • Review snippets in collapsible panels
  • Delete irrelevant, add manual notes
  • Request re-extraction if needed
Output
  • Evidence database with citations
  • Coverage rate: >85%
  • Status: Evidence Extracted
4
5
Cross-Validation
The Immune System - detecting inconsistencies
Agent Actions
  • Completeness: verify coverage status
  • Consistency: cross-check dates, names, IDs
  • Compliance: validate protocol requirements
  • Generate Info/Warning/Error flags
Human Actions
  • Review coverage summary
  • Override assessments with expert judgment
  • Add contextual notes for gray areas
Output
  • Validation results per requirement
  • False positive rate: <5%
  • Status: Cross-Validated
5
6
Report Generation
The Synthesis - crystallizing into artifact
Agent Actions
  • Compile findings into structured report
  • Generate JSON + human-readable formats
  • Include executive summary, per-req entries
  • Add provenance and appendices
Human Actions
  • Review for completeness and clarity
  • Request regeneration if needed
  • Export in preferred format
Output
  • Registry Review Report (JSON + PDF)
  • Citation completeness: 100%
  • Status: Report Generated
6
7
Human Review
The Expert Eye - judgment and decision
Agent Actions
  • Present report in editable interface
  • Track all edits with timestamps
  • Support revision workflows
  • Maintain complete change log
Human Actions
  • Edit narrative, override assessments
  • Request proponent revisions
  • Make final determination:
  • Approve / Conditional / Reject / Hold
Output
  • Finalized report with annotations
  • Complete audit trail
  • Status: Human Review Complete
7
8
Completion
The Exhalation - finalizing and archiving
Agent Actions
  • Lock finalized report
  • Generate final package with checksums
  • Prepare on-chain registration data
  • Archive all session materials
Human Actions
  • Final sign-off on review
  • Submit for on-chain registration
  • Communicate decision to proponent
  • Note lessons learned
Output
  • Locked report + audit trail
  • On-chain registration data
  • Status: Completed
