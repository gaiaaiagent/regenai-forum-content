Architecture Tiers

Client Layer - User interfaces and AI platforms
Bridge Layer - REST API translation
MCP Layer - Core registry review intelligence
Data Layer - Documents and session state

1ChatGPT File Upload Flow

User requests upload via ChatGPT. GPT calls /generate-upload-url. User clicks link, uploads files via browser form. Returns to ChatGPT, which calls /process-upload/{id} to create session.

2Claude Code Direct Flow

Native MCP client connects directly to the server. Full tool access including local file handling. No REST bridge needed - uses MCP protocol natively.

3Workflow Orchestration

All clients access identical workflow stages: session creation, document discovery, requirements mapping, evidence extraction, cross-validation, and report generation.

4Universal Accessibility

REST API enables any HTTP-capable system to leverage registry review intelligence. OpenAPI schema auto-generates documentation for ChatGPT Actions integration.
