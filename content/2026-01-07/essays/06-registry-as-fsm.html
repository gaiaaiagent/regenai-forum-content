Registry Review Agent: Eight-Stage State Machine

A deterministic workflow for carbon credit verification

1
Initialize
Establish review context and prepare workspace
In: Project name, files/links, checklist template
Out: Session ID, resource descriptors, status: Initialized
2
Document Discovery
Identify, normalize, and classify all documents
In: Configured folder/links, initialized session
Out: Document inventory with classifications
3
Requirement Mapping
Connect documents to checklist requirements
In: Document inventory, checklist template
Out: Mapping matrix with confidence scores
4
Evidence Extraction
Extract data points and text snippets
In: Mapped documents, requirement definitions
Out: Evidence snippets with page citations
5
Cross-Validation
Verify consistency and compliance across evidence
In: Extracted evidence, validation rules
Out: Coverage stats, validation flags
6
Report Generation
Produce structured, auditable review report
In: Validated evidence, session metadata
Out: JSON + Markdown reports with provenance
7
Human Review
Expert validation, annotation, and decision
In: Generated report, flagged items
Out: Annotated report, approval decision
8
Completion
Finalize and prepare for on-chain registration
In: Approved report, reviewer sign-off
Out: Locked report, audit trail, archive
State Transition Rules
✓ Proceed to next stage
↻ Loop back (re-run stage)
⚠ Escalate/Branch to revision
✗ Block (missing requirements)
❚❚ Pause (on hold)
Initialize → Discovery → Mapping → Extraction → Validation → Report → Review → Complete
The Mario Metaphor
"Each review session progresses through eight carefully designed stages, a journey I likened to playing Mario, trying to reach level eight. You cannot skip from World 1-1 to World 8-4. You must progress through each level, accumulating power-ups and capabilities along the way. The linear progression is not a limitation; it is the fundamental architecture that makes the system reliable, auditable, and trustworthy."
