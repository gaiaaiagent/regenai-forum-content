> 
> `★ Insight ─────────────────────────────────────`
> The hooks API has event-specific schemas because different events serve different purposes:
> - **SessionStart/UserPromptSubmit**: Can inject context into the conversation (before Claude responds)
> - **Stop/SubagentStop**: Control whether Claude continues working (after Claude has already responded)
> - **SessionEnd**: Cleanup only, no context injection possible
> 
> The temporal plugin assumed all events could inject context, but Stop hooks fire *after* Claude's response is complete—there's no conversation to inject into at that point.
> `─────────────────────────────────────────────────`
>
